# TrakerPOO
TrackerPOO ayuda a quien va al gimnasio a dejar de anotar sus rutinas "a ojo". Registras un entrenamiento (ejercicio, series, repeticiones, peso o tiempo, y el RIR, que es cuántas repeticiones te sobraban antes del fallo), el programa calcula el trabajo total que hiciste y lo compara con tu meta: hipertrofia, perder peso o ganar peso.
